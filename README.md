# Spider Man Settings
Configuration utility for Spider-Man (2001). It allows you to change the screen resolution, aspect ratio, color depth, and brightness, as well as enable additional enhancements, including Xbox controller support, vibration, a frame rate limiter, and other features.

Widescreen resolutions are supported, including `16:9`, `21:9`, and `32:9`. Compatibility has been tested with the English version of the game, as well as Russian translations by 7Volk and Fargus.

# Features and Improvements
- **Widescreen resolutions.** Fixed object culling beyond the screen boundaries and corrected the scaling of objects using the projection characteristic of the PS1 version of the game, such as Venom's tentacles.
- **HUD improvements.** Added two HUD layouts: an enhanced layout with optimally positioned elements and a classic layout that closely resembles the game's original design.
- **Automatic save loading.** The first save slot is automatically loaded when the game starts.
- **Improved controller support.** Added DInput-to-XInput call translation using [DInputAdvance](https://github.com/r57zone/DInputAdvance), including vibration support. Implemented vibration when taking damage. Fixed the confirm button in menus and controller input during cutscenes.
- **Audio fix.** Fixed background music stuttering in the Scorpion level.

## Installation
1. Close the game if it is running.
2. Download the [archive](https://github.com/r57zone/Spider-Man-Settings/releases) and extract its entire contents into the game folder.
3. Run `Spider-Man Settings` and select the desired options.
4. Click `Apply`. The application will patch the necessary game files.
5. In the game's properties, set `Compatibility Mode` to `Windows XP Service Pack 2` to fix audio issues.
